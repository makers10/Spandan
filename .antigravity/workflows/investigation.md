# Investigation Workflow

## Steps
1. **Hypothesis Definition:** State clear question or phenomenon to investigate (e.g. sensor drift, frame drops).
2. **Read-Only Inspection:** Search symbols and read relevant source files without making changes.
3. **Data Collection:** Gather sensor telemetry logs, test outputs, or performance traces.
4. **Isolate Variables:** Test hypotheses one at a time using scratch scripts in `scratch/`.
5. **Formulate Recommendation:** Document findings with evidence before proposing implementation.
6. **User Alignment:** Present clear trade-offs, root cause, and proposed plan before modifying code.
